# 阶段 10：游戏专项毕业项目

**类型**：必修。选择一个真实游戏方向：

- 2D Roguelike/塔防：Sprite batching、图集、粒子、遮挡、灯光、后处理。
- 3D 卡通动作：Toon、描边、角色材质、阴影、技能特效。
- 3D 写实 RPG：PBR、IBL、阴影、LOD、后处理。
- 俯视角/等距游戏：Tilemap、深度排序、2.5D 光照和遮挡。

交付：技术需求说明、渲染方案和模块图、可运行 Demo、源码、关键 Shader 说明、平台兼容记录、性能预算与实测、已知限制和复盘。

**通过标准**：解决一个具体游戏画面问题；可复现运行；能解释关键实现；有目标设备数据。

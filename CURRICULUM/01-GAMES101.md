## 知识模块

### 01 向量与矩阵

- 向量规范化、点积与叉积
- 矩阵乘法、转置与逆
- 向量与矩阵在图形学中的应用

### 05 几何

- 细分曲面与简化

### 06 光线追踪

- Whitted 风格光线追踪
- 光线-物体求交
- BVH 加速结构
- 路径追踪入门

## 关键公式备忘

```
Blinn-Phong:
  L = L_ambient + L_diffuse + L_specular
  L_diffuse = k_d * (I / r²) * max(0, n·l)
  L_specular = k_s * (I / r²) * max(0, n·h)^p

透视投影矩阵:
  [ n/r  0    0               0  ]
  [ 0    n/t  0               0  ]
  [ 0    0   -(f+n)/(f-n)  -2fn/(f-n) ]
  [ 0    0   -1              0  ]
```

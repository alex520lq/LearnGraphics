# 实战项目

存放从零构建的完整图形学项目，作为阶段性学习成果的集中展示。

## 规划项目

| 编号 | 项目 | 技术栈 | 目标阶段 | 状态 |
|------|------|--------|----------|------|
| P01 | 软光栅化器 | C++ | 01 | 未开始 |
| P02 | 迷你光线追踪器 | C++ | 01 | 未开始 |
| P03 | WebGL 3D 场景 | WebGL2 / TypeScript | 02 | 未开始 |
| P04 | 自研渲染器 | OpenGL / C++ | 03 | 未开始 |
| P05 | Shader 作品集 | GLSL / Shadertoy | 04 | 未开始 |
| P06 | PBR 材质查看器 | WebGL2 / glTF | 05 | 未开始 |
| P07 | 实时阴影与 GI Demo | OpenGL / Vulkan | 06 | 未开始 |
| P08 | 渲染器性能优化实战 | C++ / RenderDoc | 07 | 未开始 |

## 项目结构规范

```
PROJECTS/
└── <项目名称>/
    ├── README.md       # 项目介绍、运行方式、效果展示
    ├── src/            # 源代码
    ├── assets/         # 模型、纹理、着色器资源
    ├── docs/           # 设计文档与技术总结
    └── screenshots/    # 效果截图
```

## 项目 README 要求

- 一句话项目描述
- 技术栈与依赖
- 构建与运行步骤
- 核心实现说明
- 效果截图或演示链接
- 已知问题与后续计划

# Tracking — 进度与问题跟踪

- 根目录 [PROGRESS.md](../PROGRESS.md)：阶段看板和总进度。
- [LESSON-TEMPLATE.md](LESSON-TEMPLATE.md)：每节课记录模板。
- [ISSUE-TEMPLATE.md](ISSUE-TEMPLATE.md)：GitHub Issue 模板。

## 每周记录

每周更新 PROGRESS.md 的日志表：学习主题、投入时间、代码/文档产出、未解决问题和下周计划。

## 状态定义

未开始 / 进行中 / 待验收 / 复习中 / 已完成 / 暂停。

## 问题记录

遇到问题时记录现象、环境、最小复现、排查步骤、根因、解决方案和相关提交。不要只粘贴报错，不记录排查过程。

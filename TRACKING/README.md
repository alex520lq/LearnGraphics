# Tracking — 进度与问题跟踪

- 根目录 [PROGRESS.md](../PROGRESS.md)：阶段看板、当前课程、验收状态和学习日志。
- 根目录 [WORKFLOW.md](../WORKFLOW.md)：每课提交、代码审查、下一课工程初始化和教学流程。
- [LESSON-TEMPLATE.md](LESSON-TEMPLATE.md)：每节课记录模板。
- [ISSUE-TEMPLATE.md](ISSUE-TEMPLATE.md)：GitHub Issue 模板。

## 进度维护规则

每次课程验收后更新 PROGRESS.md；每次实验通过后，在对应 LABS 实验 README 记录结论和证据。必须区分源码已确认、运行证据已确认、学习者自述和待补交内容。不得只根据聊天中的“完成了”将课程标为通过。

## 每周记录

每周更新学习主题、投入时间（仅记录实际提供的数据）、代码/文档产出、未解决问题和下周计划。

## 状态定义

未开始 / 进行中 / 待验收 / 待补交 / 修改后复验 / 已通过 / 复习中 / 暂停。

## 问题记录

遇到问题时记录现象、环境、最小复现、排查步骤、根因、解决方案和相关提交。不要只粘贴报错，不记录排查过程。

# LearnGraphics

**计算机图形学 · 实时渲染 · 游戏图形编程**

一个系统化的图形学学习与知识沉淀仓库，覆盖从数学基础到实时渲染引擎开发的完整路径。

## 学习目标

- 掌握计算机图形学核心数学基础与渲染管线原理
- 理解实时渲染技术栈：WebGL / OpenGL / Vulkan / DirectX
- 熟练编写 GLSL / HLSL Shader
- 实现 PBR 光照、阴影与全局光照等高级渲染特性
- 具备游戏图形引擎渲染模块的开发与优化能力

## 学习路径概览

| 阶段 | 主题 | 核心产出 |

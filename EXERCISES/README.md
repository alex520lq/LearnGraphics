# 练习与作业

存放各阶段的编程练习、课程作业与代码挑战。

## 命名规范

```
EXERCISES/
└── <阶段编号>-<主题>/
    ├── README.md       # 题目说明与要求
    ├── src/            # 源代码
    └── result/         # 运行截图与结果
```

示例：`EXERCISES/01-games101-hw2/`

## 记录要求

每个练习目录的 `README.md` 应包含：

- 题目来源与目标
- 实现思路
- 关键代码片段
- 运行结果（截图/录屏）
- 遇到的问题与解决过程

# Exercises — 练习与作业

练习是每个课程阶段的实践验收。按阶段编号归档，源码与运行证据放在同一目录。

## 目录规范

```
EXERCISES/
├── 01-Math/
├── 02-GAMES101/
├── 03-WebGL/
├── 04-Renderer/
├── 05-Shader/
├── 06-PBR/
├── 07-PostFX/
└── 08-MiniGame/
```

每份作业包含：题目来源、目标、运行环境、启动方法、实现思路、源码、截图/录屏、验收问题、Bug 排查和游戏应用场景。

## 验收原则

先独立完成，再参考教程或 AI；不能解释的代码不算掌握；无法复现的结果不算完成。具体学习顺序以根目录 ROADMAP.md 为准。

# 学习笔记

记录学习过程中的概念理解、公式推导、踩坑经验与技术总结。

## 分类方式

```
NOTES/
├── concepts/       # 概念理解
├── formulas/       # 公式推导
├── pitfalls/       # 踩坑记录
└── summaries/      # 阶段总结
```

## 笔记模板

```markdown
# 标题

## 背景
为什么需要这个知识点，解决什么问题。

## 核心内容
关键概念、公式、流程（配图更佳）。

## 我的理解
用自己的话复述，检验是否真正理解。

## 关联
与其他知识点的联系，相关资源链接。

## 参考
- 链接 1
- 链接 2
```

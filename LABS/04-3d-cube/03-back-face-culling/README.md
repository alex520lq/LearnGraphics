# 子实验 03：Back-face Culling（背面剔除）

- 所属课程：第 04 课 3D 坐标、深度测试与立方体
- 状态：未开始
- 核心问题：GPU 如何根据三角形绕序识别正面和背面，并剔除背面？

## 前置

子实验 02 Cube Mesh 已通过；已有可显示的立方体和正确深度测试。

## 本实验只学习

- 三角形顶点绕序：CCW / CW。
- `gl.frontFace()` 的正面约定。
- `gl.cullFace()` 的剔除目标。
- `gl.enable(gl.CULL_FACE)`。
- 修改单个面的索引顺序观察结果。

本实验不重新实现立方体 Mesh；沿用子实验 02 的几何数据。

## 任务

1. 先在关闭面剔除时确认立方体正常。
2. 设置 `gl.frontFace(gl.CCW)`。
3. 设置 `gl.cullFace(gl.BACK)` 并启用 `gl.CULL_FACE`。
4. 观察立方体可见面。
5. 反转一个三角形的索引顺序，观察该面变化。
6. 对比剔除开启和关闭的画面。

## 验收标准

- [ ] 能说明 CCW 和 CW 的含义。
- [ ] 启用背面剔除后，立方体外表面仍正确可见。
- [ ] 反转一个面的绕序后，能观察到预期剔除变化。
- [ ] 能说明 `frontFace` 与 `cullFace` 的区别。
- [ ] 提交源码、对照截图和 Console 结果。

# 第 04 课：3D 坐标、深度测试与立方体

- 阶段：03 原生 WebGL 1.0
- 类型：必修
- 状态：已初始化，待学习
- 前置：第 01～03 课；理解 Buffer、Attribute、索引绘制和 Mesh 数据
- 目标：从 2D 索引矩形过渡到具有深度关系的 3D Mesh，为游戏场景中的模型绘制打基础。

## 本课目标

1. 区分对象/模型坐标、裁剪空间和屏幕显示。
2. 使用 3D 顶点数据描述立方体。
3. 使用索引缓冲区组织三角形面。
4. 理解并启用深度测试（Depth Test）。
5. 理解三角形绕序（Winding Order）和背面剔除（Back-face Culling）。
6. 能解释为什么 3D 场景不能只依赖绘制顺序决定前后遮挡。

## 工程文件

- `index.html`：实验页面。
- `main.js`：WebGL 初始化与待完成代码骨架。

## 运行方式

使用 VS Code Live Server 打开本目录的 `index.html`。浏览器打开后查看页面和 DevTools Console。

## 实验任务

### A. 3D 顶点与索引 Mesh
- [ ] 将顶点从二维坐标扩展为三维坐标。
- [ ] 定义立方体的顶点属性和索引。
- [ ] 用 `gl.drawElements()` 绘制立方体表面。
- [ ] 记录顶点数量、索引数量和三角形数量。

### B. 深度测试
- [ ] 启用 `gl.DEPTH_TEST`。
- [ ] 每帧清理颜色缓冲和深度缓冲。
- [ ] 对比开启/关闭深度测试时的遮挡结果。
- [ ] 解释深度测试解决的问题。

### C. 三角形绕序与背面剔除
- [ ] 理解顺时针和逆时针绕序。
- [ ] 启用 `gl.CULL_FACE` 并观察结果。
- [ ] 改变一个面的索引顺序，观察该面是否被剔除。
- [ ] 说明正面定义与 `gl.frontFace()`、`gl.cullFace()` 的关系。

## 重要提示

本课先关注 3D 几何、深度缓冲和面剔除，不要求一次性实现完整相机系统。若课程中加入旋转或投影变换，会明确给出矩阵约定和验证方法。WebGL 1.0 使用 GLSL ES 1.00 语法。

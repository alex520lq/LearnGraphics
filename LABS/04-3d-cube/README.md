# 第 04 课：3D 坐标、深度测试与立方体

- 阶段：03 原生 WebGL 1.0
- 类型：必修
- 状态：进行中（按子实验逐项验收）
- 前置：第 01～03 课；理解 Buffer、Attribute、索引绘制和 Mesh 数据
- 课程目标：理解 3D 深度关系、立方体 Mesh、三角形绕序和背面剔除，为游戏场景模型绘制打基础。

## 课程设计

本课拆分为三个独立实验。每个实验只聚焦一个核心问题，拥有独立的 HTML、JavaScript 和 README，可单独运行、提交和验收。必须按顺序完成，不一次性完成全部实验。

| 顺序 | 子实验 | 核心问题 | 验收产物 | 状态 |
|---|---|---|---|---|
| 01 | [Depth Test](01-depth-test/) | 物体重叠时，GPU 如何判断谁在前面？ | 两个不同深度三角形 + 绘制顺序对照 | 当前进行 |
| 02 | [Cube Mesh](02-cube-mesh/) | 如何用 3D 顶点和索引构建立方体？ | 可见的 3D 立方体 Mesh | 已通过（源码逻辑验收） |
| 03 | [Back-face Culling](03-back-face-culling/) | GPU 如何根据绕序识别并剔除背面？ | 剔除开关与绕序对照实验 | 未开始 |

## 学习规则

- 一次只学习一个子实验。
- 当前子实验源码和运行证据验收通过后，才开始下一子实验。
- 每个子实验的验收结论写入对应子目录 README，并更新根目录 `PROGRESS.md`。
- 本课三个子实验全部通过后，才标记第 04 课完成。

## 运行方式

分别进入子实验目录，使用 VS Code Live Server 打开该目录自己的 `index.html`。

## 本课最终能力

- 理解 WebGL NDC 深度与窗口深度映射。
- 使用深度缓冲正确处理前后遮挡。
- 组织 3D Mesh 顶点属性与索引。
- 理解三角形绕序、正面定义和背面剔除。

# 子实验 02：Cube Mesh（立方体网格）

- 所属课程：第 04 课 3D 坐标、深度测试与立方体
- 状态：已初始化，待学习
- 核心问题：如何用 3D 顶点属性和索引数据描述一个立方体？

## 前置

子实验 01 Depth Test 已通过；理解 vec3 顶点、Buffer、Attribute、drawElements 和深度缓冲。

## 本实验只学习

- 立方体的 8 个空间角点。
- 六个面、每面两个三角形。
- Mesh 的 positions、colors、indices。
- 顶点 Buffer 与索引 Buffer 的上传。
- 使用 `gl.drawElements()` 绘制立方体。
- 深度测试在立方体面之间的遮挡作用。

本实验暂不研究背面剔除；不要启用 `gl.CULL_FACE`。本实验也暂不引入模型、观察、投影矩阵。顶点位置直接按当前 Shader 所需的裁剪空间坐标组织，目的是先隔离 Mesh 与索引数据的学习目标。

## 任务

1. 使用 8 个顶点记录表示立方体的前后两个面。
2. 每个顶点包含 3 个位置分量（x、y、z）。
3. 为 8 个顶点各定义一组 RGB 颜色。
4. 定义 36 个索引，组成 12 个三角形，覆盖六个面。
5. 创建并上传两个 `ARRAY_BUFFER`：positions 与 colors。
6. 创建并上传一个 `ELEMENT_ARRAY_BUFFER`：indices。
7. 配置两个顶点 Attribute。
8. 启用 `DEPTH_TEST` 和 `LESS`，每次绘制前清理颜色与深度缓冲。
9. 使用 `gl.drawElements(gl.TRIANGLES, 36, gl.UNSIGNED_SHORT, 0)` 绘制。

## 重要提示

- 8 个顶点是 8 条完整的顶点属性记录，不只是 8 个位置。
- 索引值必须在 0～7 范围内。
- 索引数量必须是 36。
- 每个三角形由 3 个索引组成，因此 36 个索引对应 12 个三角形。
- 因为本实验不启用背面剔除，三角形绕序暂时不会导致背面消失；绕序将在子实验 03 单独学习。

## 验收标准

- [ ] positions 长度为 24（8 × 3）。
- [ ] colors 长度为 24（8 × 3）。
- [ ] indices 长度为 36，且所有索引均为 0～7。
- [ ] 六个面均由两个三角形构成。
- [ ] 使用 `ELEMENT_ARRAY_BUFFER` 和 `Uint16Array`。
- [ ] 使用 `drawElements` 提交 12 个三角形。
- [ ] 开启深度测试后，立方体前后面遮挡关系正确。
- [ ] 未启用背面剔除。
- [ ] 能解释为什么 8 个顶点记录可以通过索引被多个三角形共享。
- [ ] 提交源码；无需强制截图，优先通过源码结构与绘制逻辑验收。

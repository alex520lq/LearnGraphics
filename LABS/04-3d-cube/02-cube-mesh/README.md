# 子实验 02：Cube Mesh（立方体网格）

- 所属课程：第 04 课 3D 坐标、深度测试与立方体
- 状态：未开始
- 核心问题：如何用 3D 顶点属性和索引数据描述一个立方体？

## 前置

子实验 01 Depth Test 已通过；理解 vec3 顶点、Buffer、索引绘制和深度缓冲。

## 本实验只学习

- 3D 顶点位置。
- 六个面、每面两个三角形。
- 3D Mesh 的 positions、colors、indices。
- 用 `gl.drawElements()` 绘制立方体。
- 深度测试在立方体面之间的遮挡作用。

本实验暂不研究背面剔除；立方体应先在不启用 CULL_FACE 的情况下正确显示。

## 任务

1. 选择 8 顶点共享角点的立方体布局。
2. 为 8 个顶点定义颜色。
3. 定义六个面的三角形索引，共 36 个索引。
4. 上传位置、颜色和索引 Buffer。
5. 启用深度测试并绘制立方体。

## 验收标准

- [ ] 8 个顶点，每个顶点 3 个位置分量。
- [ ] 8 组 RGB 颜色。
- [ ] 36 个索引，组成 12 个三角形。
- [ ] 画面能看到立方体多个面，前后遮挡正确。
- [ ] 能解释为什么本实验暂时不启用背面剔除。
- [ ] 提交源码、运行截图和 Console 结果。

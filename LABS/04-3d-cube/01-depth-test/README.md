# 子实验 01：Depth Test（深度测试）

- 所属课程：第 04 课 3D 坐标、深度测试与立方体
- 状态：等待运行证据（第二次源码复查已确认修正）
- 核心问题：两个三角形覆盖同一屏幕区域时，GPU 如何决定哪个可见？

## 本实验只学习

- 顶点位置从 vec2 扩展为 vec3。
- NDC Z 与窗口深度值的关系。
- `gl.DEPTH_TEST`、`gl.depthFunc(gl.LESS)`。
- 清理颜色缓冲和深度缓冲。
- 绘制顺序与深度测试的关系。

本实验不构建立方体、不启用背面剔除。

## 运行

使用 Live Server 打开本目录的 `index.html`。

## 任务

1. 创建两个 X/Y 覆盖区域相同、Z 不同的三角形。
2. 远处三角形设为红色，近处三角形设为蓝色。
3. 分别测试开启和关闭深度测试。
4. 开启深度测试时交换两次 drawArrays 的调用顺序。
5. 记录重叠区域最终颜色，并解释原因。

提示：WebGL 默认 NDC Z 范围为 [-1, 1]，窗口深度范围默认映射到 [0, 1]；默认深度比较为 LESS 时，较小深度值通过测试。请从实验结果验证，不要只背结论。

## 验收标准

- [ ] 关闭深度测试后，重叠区域受绘制顺序影响。
- [ ] 每次清屏时正确清理深度缓冲。
